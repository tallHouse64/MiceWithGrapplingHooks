
# Mice With Grappling Hooks

This is a 2D game where you can fly around as a mouse using a grappling hook.


## Installing

To install MWGH, go to the releases page. Windows and Linux are supported.

Note that the Linux build is only tested for Manjaro Linux, you also need to install SDL2 or SDL3 with the SDL2 compatibility layer.


## Compiling

To compile MWGH read 'Compiling' in CONTRIBUTING.md.
